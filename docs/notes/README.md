# Nhật ký làm việc

Các ghi chép viết trong lúc dò (04–07/10/2026). Chúng được giữ nguyên để thấy đường đi, **kể cả
những nhận định về sau bị bác**. Muốn biết kết quả cuối cùng thì đọc
[`../protocol.md`](../protocol.md) và [`../bench-power.md`](../bench-power.md).

|---|---|---|

trình đo chưa thực hiện) đã được bỏ khỏi repo; chúng vẫn nằm trong lịch sử git.
